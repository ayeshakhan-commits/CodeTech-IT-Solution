# Smart Public Transportation Analysis & Interactive BI Dashboard

## 🚌 Project Overview
An end-to-end data analytics and Business Intelligence dashboard project completed during my Data Analytics internship. The project transforms raw unformatted transportation log data into a structured data pipeline, exposing actionable operational insights through an executive-level interactive BI dashboard.

## 📊 Key Performance Indicators (KPIs)
- *Total Passengers Processed:* 24,920
- *Total Ticket Revenue Generated:* Rs. 2,501,000.00
- *Average Route Delay:* 15.47 Minutes

## 🛠️ Tech Stack & Workflow
1. *Data Cleaning & Wrangling:* Handled unformatted delimiter logs using Python (Pandas) inside Jupyter Notebook to generate clean structural schemas.
2. *Data Transformation:* Processed using Excel's Text-to-Columns delimiter mapping to successfully isolate route segments, delay durations, and revenue figures.
3. *BI Dashboard & Modeling:* Formulated cross-sheet interactive dashboards featuring Pivot Tables, synchronized multi-variable Slicers (Trip_Status, Bus_Type), and Revenue Performance charts.
